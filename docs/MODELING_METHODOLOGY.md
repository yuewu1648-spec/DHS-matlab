# 建模方法论（agent 的方法学母本）

本文件是 preset persona 与 `bridge/skills/` 的内容母本，解释 agent 为什么这样工作、每个质量门在防什么错误。

## 1. 立场：从文献证据到可证伪模型

生物系统建模不是"把文献里的数字代进公式"，而是：

1. 从文献抽取**机制主张**（谁调控谁、正/负、直接/间接、时空尺度）与**定量事实**（参数、初值、观测量、条件）；
2. 选择或组合**典范机制**（archetype）与**第一性原理**（质量作用、守恒、量纲、QSSA、扩散、电化学势、热力学约束……）写出候选模型；
3. 明确**建模假设**并给出**可证伪预测**：模型在什么实验条件下会给出与替代机制不同的结果；
4. 用 MATLAB 做结构分析、仿真、参数估计、可辨识性、交叉验证；
5. 报告结论连同不确定性、替代模型比较和局限。

质量门的作用是防止四种常见失败：**证据漂移**（结论无出处）、**单位灾难**（量纲不自洽）、**过拟合/不可辨识**（参数无约束却给 CI）、**假验证**（拟合好=模型对）。

## 2. 质量门与失败模式

| 门 | 动作 | 防的错误 |
|---|---|---|
| G0 环境 | `matlab_status`（版本/授权/health/workspace_writable） | 用错后端/版本，产物散落；卡死不可见 |
| G1 文献 | `bma_literature_ingest` + 逐字证据表 + `figures.json` 图清单（BLIND-LIT 模式下不适用：改用 B1/B3，见 §8） | 凭印象编参数；摘要式敷衍；漏掉文献图 |
| G2 知识 | `bma_kb_search/get` | 机制族选错；漏掉守恒/量纲约束 |
| G2.5 图目标 | 为每个必复现 panel 写清图号/caption/轴/条件/模型输出/判据 | 只挑最容易的图；把示意图当数据图 |
| G3 假设 | ≥2 候选机制 + 可证伪预测 | 先入为主；不可检验的模型 |
| G4 规格 | 写 `bma.modelSpec.v1`，参数带 evidence/assumed | 无溯源；单位缺失；速率定律非法 |
| G5 校验 | `bma_model_validate` 必过 | 带着结构错误往下算 |
| G6 结构 | `bma_model_analyze`（仅 ODE/MOL；2D/3D 原生 PDE 用 probes/field_stats） | 模型自相矛盾（守恒破坏、无稳态、量纲错）；符号求解卡死 |
| G6.5 求解器前置 | 写任何自写求解循环前做 A2 雅可比方向导数 + A3 方程残差验收，写入 `solver_preflight.json` | 未验证 J 就写 Newton；用 `||u_new-u||` 当收敛；钳位后不重算残差 |
| G7 仿真 | 1D/需 fit → `bma_model_simulate(_cases)`；真正 2D/3D/非规则几何且预算允许 → `bma_pde_simulate`（PDE Toolbox，不转 ODE）；条件对齐文献图；经典形式优先（极限环相图/剂量响应/双稳/酶 v-S/时空场） | 不复现文献现象就硬拟合；2D/3D 强行 MOL 或超 max_dof 盲目重跑；用通用图冒充文献图/经典图 |
| G8 参数 | `bma_model_fit` + `identifiability` + `sensitivity`（超时先取消） | 过拟合；不可辨识参数给假 CI；重任务拖死会话 |
| G9 交付 | `validate_fit`/`model_selection`/`report_build`/`codegen`/`artifact_import`；报告含“文献图复现”矩阵（成功+失败 panel） | 无验证、无对比、无复现；报告依赖外部绝对路径；只报成功的图 |

### 2.1 计算不可行时的豁免（0.5.0）

G6/G8 可能遇到“符号不可解/单次调用超时”的计算不可行情形。正确做法不是无限等待，也不是静默跳过：

1. `bma_model_analyze` 自动预判符号难度并返回 `symbolic_skipped` + 数值替代；这是合格结果。
2. 仍不可行时，用 `bma_gate_waive(gate, reason, substitute, evidence)` 把豁免写入 `gates.json`；报告与 model card 会显示。
3. 豁免必须同时给出**替代证据**（数值守恒零空间、数值 Jacobian、局部敏感性、1-D 解析对照等），不能只写“跑不动”。
4. 即使豁免，也要在报告局限中说明“该门未完成/降级”，不得声称已完成。

## 3. 生物系统学的核心建模语言

- **层次**：分子 → 通路/网络 → 细胞 → 组织 → 器官 → 个体 → 种群 → 生态系统。层次决定模型类别：分子/通路常用 ODE（质量作用、米氏、Hill），组织常用反应-扩散 PDE/Turing，细胞群体可用离散/随机（CME、Gillespie），种群用 ODE/离散/统计。
- **变量选择**：只把文献明确测量的或机制必需的量作为状态变量；其余用代数关系/QSSA 消去。状态变量必须有单位和物理范围。
- **通量与守恒**：每个反应写化学计量；检查 S 的左零空间（守恒量，如 E+ES、S+I+R、NADH 池）；守恒破坏通常意味着漏了反应或组分。
- **速率定律选择**：基元步骤用质量作用；酶催化在 QSSA 下用米氏；协同/阈值用 Hill；复杂机制用受限表达式（但必须量纲自洽）。
- **参数来源**：文献实测 > 文献拟合/估计 > 合理 assumed（给依据）> 自由拟合（给 CI）。不可辨识时报告组合量（Km、Vmax、R0、周期）。
- **时间尺度**：快变量可 QSSA；慢变量决定振荡/适应；τ≈1/k 与采样间隔比较可判断可辨识性（未采到的瞬态无法恢复其参数）。

## 4. 数学/物理/化学生物学的常用关系

| 知识 | 形式 | 典型用途 |
|---|---|---|
| 质量作用定律 | v = k ∏ x_i^{n_i} | 基元反应、结合/解离 |
| 米氏方程 | v = Vmax S/(Km+S) | 酶催化（QSSA） |
| Hill 函数 | v = Vmax x^n/(K^n+x^n) | 协同结合、基因调控阈值 |
| 化学计量/守恒 | S 的左零空间 | 守恒律、结构诊断 |
| 量纲分析 | 速率密度=浓度/时间 | 单位校验、无量纲化 |
| Fick 定律 | J = -D ∇c | 扩散、反应-扩散 |
| Nernst 方程 | E = (RT/zF) ln(c_out/c_in) | 膜电位、离子驱动 |
| 热力学约束 | ΔG = ΔG° + RT ln Q | 反应方向、详细平衡 |
| 随机性 | Poisson/Fano factor、CME | 小分子数噪声、基因表达爆发 |
| 网络基序 | 正/负反馈、前馈环、双稳态 | 振荡、适应、开关 |
| 稳定性 | Jacobian 特征值、Hopf 分岔 | 稳态稳定性、振荡条件 |
| R0/NGM | R0 = 谱半径(K) | 流行病阈值、干预评估 |

## 5. 拟合与可辨识性的方法学

1. 只估真正未知的参数；文献已报道且可信的固定。
2. 有界多起点；从文献值/典型范围/±log 扰动出发。
3. 报告指标（R²、RMSE、NRMSE、AICc/BIC）+ 参数 CI + 可辨识性结论。
4. 若参数只以组合出现（相关≈1、剖面平坦），报告组合量与物理解释。
5. 拟合好但残差有结构 → 模型缺机制；比较竞争模型（AICc 权重），不要加无根据参数。
6. 交叉验证（时序分折）> 单次拟合指标；报告测试集表现。

## 5.1 数值自检（0.5.0，尤其自建 PDE/FEM）

求解器返回 `exitflag=1`/残差小，只证明离散方程被满足，不证明物理正确。任何新数值实现至少执行：

1. 无源/边界检验（`f=0` 时 `u≈u_amb`）；
2. 反应体积/区域检查（`V_isl>0`，接近解析面积/体积）；
3. 算子零空间（纯扩散时 `norm(K*ones)≈0`）；
4. 方向检验（源强翻倍，监测点按物理方向单调变化）；
5. 归一化残差 `norm(K*u-F)/(norm(K)*norm(u_ref))`，不要用 `|r|/c_amb`；
6. 1-D/球解析极限对照与网格/时间步收敛。

详细清单见 KB `numerical_convergence_checklist` 与 `matlab_pde_toolbox_pitfalls`。自检证据（JSON/CSV/PNG）放入 `run_dir/artifacts/` 并在报告中引用。

## 6. 报告与诚信

- 中文报告，结构：结论 → 模型 → 证据与参数 → 验证 → 局限 → 下一步实验。
- 参数证据表：值/单位/类型（measured/estimated/assumed/fitted）/来源 quote 或 CI。
- 假设与局限必须具体（哪个参数不可辨识、哪组条件未覆盖、哪个竞争机制未排除）。
- 不编造文献/DOI/数值；未运行的步骤不得声称完成。
- 交付物：报告（HTML/MD）、模型卡、spec JSON、数据、代码（.m，可选 SimBiology）、图。

## 8. BLIND-LIT：只有摘要与参考文献时的建模方法论（0.15.0）

普通流程假设能通读主文献；BLIND-LIT 把前提改成“只知道主文献在问什么（摘要）”。这不是“更难的复现”，而是**预注册式盲建模**：模型必须在看到结果之前就可证伪。

### 8.1 质量门映射

| 普通门 | BLIND-LIT 替代 | 防的错误 |
|---|---|---|
| G1 文献 | B1 封印（只读摘要）+ B3 逐篇参考文献（quote 工具核验） | 偷看全文；摘要式敷衍；只读一部分 |
| G1 图目标 | 不适用（主文献图不可见）；只登记参考文献中的图 | 把主文献结果当已知 |
| G3 假设 | B4 ≥2 候选机制 + 可证伪预测（证据只能来自参考文献） | 先入为主；不可检验 |
| G4 规格 | B4 spec（参数 evidence 只能来自参考文献或 assumed/fitted） | 伪造“主文献结果”引用 |
| G6/G7/G8 | 同普通流程（validate/analyze/simulate/fit/identifiability） | 结构/数值/拟合问题 |
| G9 交付 | B6 stop + blind_summary + 可选 B7 对照 | 假停止；事后改写历史 |

### 8.2 为什么要有“自检轮次”与“问题分类”

盲建模最容易出现的失败不是算错，而是**证据不足却继续编**。协议要求每轮记录：
- 对齐（模型是否回答摘要问题）、覆盖（每篇文献是否核验）、机制（候选/证伪）、结构（守恒/量纲/稳态）、数值（仿真/拟合/可辨识性）、证据（quote 来源）、诚信（未读/未跑/局限）。

剩余问题只能：
- `fixed`：给出修复动作 + 复验证据；改模型必须提交 hash 变化的 spec（伪修复会被工具拒绝）。
- `impossible`：原则性障碍（数据不可辨识、文献互斥、模型类缺物理、全文不可得），必须写 `why_general` 解释为什么不是预算问题。
- `over_budget`：已花费 ≥2× 申报预算，且继续会成倍花费；必须给预算与证据。

### 8.3 解封对照的方法学

解封后对照不是“证明自己对”，而是**误差分析**：
- 8 维逐项比较（问题/模型类/状态变量/机制/参数/假设/行为/证据使用）；
- `partial`/`diverge` 必须给 follow_up；
- 明确哪些差异来自“摘要信息不足”，哪些来自“参考文献没有覆盖”，哪些是建模选择错误；
- 解封后才修正的内容标注“解封后修正”，不得写成盲建模时已知。

### 8.4 诚信声明（报告必须写）

- 建模期间未读取主文献全文/图/表；
- 使用了哪些参考文献、哪些是 `limited`（无全文）；
- 哪些问题以 `impossible`/`over_budget` 关闭；
- 模型对摘要问题的预测边界，以及解封后发现的差异。
